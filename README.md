## 🏛️ Sobre a CCEE

A **Câmara de Comercialização de Energia Elétrica (CCEE)** é a entidade responsável pela viabilização da comercialização de energia elétrica no Sistema Interligado Nacional (SIN) do Brasil.

Os **Procedimentos de Comercialização (PdC)** são o conjunto normativo que regulamenta todas as operações no mercado livre de energia.

🌐 **Site Oficial:** [www.ccee.org.br](https://www.ccee.org.br)
